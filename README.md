# 🤖 ASP Auto Bot

Automated Facebook group joining and posting bot for growth marketing.

## ✨ Features

- 🎯 Auto-join Facebook groups based on keywords
- 📝 Auto-post content with rotating templates
- 🕵️ Anti-detection with rotating user agents
- ❓ Auto-answer membership questions
- ⏰ Human-like scheduling and delays
- 📊 Daily statistics and reports
- 📱 Telegram notifications
- 🚫 Smart blacklist management
